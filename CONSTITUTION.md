# Constitution — GroundWork Lens

1. **No LLM, anywhere.** Every status, summary, and list is derived deterministically from git history and GroundWork files.
2. **Self-hosted.** One container inside the customer network with zero outbound calls except to configured GitHub or GitLab hosts.
3. **No orchestration.** Lens never starts or steers coding agents.
4. **One parser.** Lens never parses GroundWork markdown or front matter directly; the bundled GroundWork engine is the single parser.
5. **Plain language.** Every leader-facing screen translates internal GroundWork identifiers into plain English.
